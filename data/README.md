# Δεδομένα FlyWire (v783)

Πέντε αρχεία `.csv.gz` (τα διαβάζει κατευθείαν η `pd.read_csv`).
Το κλειδί που τα ενώνει είναι το **`root_id`**: ένας μοναδικός int64 αριθμός (~7.2·10¹⁷) για κάθε νευρώνα.

| Αρχείο | Γραμμές | Μία γραμμή = |
|---|---|---|
| `neurons.csv.gz` | 139.255 | ένας νευρώνας (νευροδιαβιβαστής) |
| `classification.csv.gz` | 139.255 | ένας νευρώνας (ιεραρχική κατηγοριοποίηση) |
| `consolidated_cell_types.csv.gz` | 138.327 | ένας νευρώνας (cell type) |
| `cell_stats.csv.gz` | 139.246 | ένας νευρώνας (μορφολογία) |
| `connections_princeton.csv.gz` | 5.342.446 | ένα ζεύγος (pre → post) **μέσα σε ένα neuropil** |

**Κάλυψη ID:** `neurons` και `classification` έχουν ακριβώς τα ίδια 139.255 ID.
Από το `cell_stats` λείπουν 9 νευρώνες, από το `consolidated_cell_types` λείπουν 928.
Κανένα αρχείο δεν έχει ID που να μην υπάρχει στο `neurons`.
→ Ένωση με `merge(..., how="left")` πάνω στο `neurons` και μετά χειρισμός των NaN.

## 5. `connections_princeton.csv.gz`: γράφος συνάψεων

| Στήλη | Τύπος | NaN | Τιμές | Σημασία |
|---|---|---|---|---|
| `pre_root_id` | int64 | 0 | 137.518 μοναδικοί | Προσυναπτικός νευρώνας (στέλνει) |
| `post_root_id` | int64 | 0 | 130.183 μοναδικοί | Μετασυναπτικός νευρώνας (λαμβάνει) |
| `neuropil` | str | 0 | 79 περιοχές (βλ. παρακάτω) | Περιοχή του εγκεφάλου όπου βρίσκονται αυτές οι συνάψεις |
| `syn_count` | int64 | 0 | 1 – 2.633 (median 6, mean 9.5) | Πλήθος συνάψεων του ζεύγους μέσα σε αυτό το neuropil |
| `nt_type` | str | 0 | `ACH` 3.21M, `GABA` 1.17M, `GLUT` 826k, `DA` 64k, `SER` 40k, `OCT` 29k | Νευροδιαβιβαστής του **pre** νευρώνα |

Σημειώσεις:
- Ένα ζεύγος (pre, post) μπορεί να εμφανίζεται σε **πολλές γραμμές**, μία για κάθε neuropil. Διπλότυπα (pre, post, neuropil) δεν υπάρχουν, ούτε self-loops.
- Άθροισμα `syn_count` = **50.666.648 συνάψεις**. Το CLAUDE.md αναφέρει «15 εκατ.», που είναι λάθος.
- 1.588.394 γραμμές έχουν `syn_count` < 5. Συχνά εφαρμόζεται κατώφλι ≥ 5 για να αφαιρεθεί ο θόρυβος.
- 671 νευρώνες δεν εμφανίζονται σε καμία σύνδεση (έχουν βαθμό 0).
- Το `nt_type` εδώ **δεν έχει NaN**, ακόμη και για τους 18.032 pre νευρώνες που έχουν `nt_type` = NaN στο `neurons`. Όπου υπάρχουν και οι δύο τιμές, συμφωνούν 100%. **Προσοχή σε leakage:** αν ο στόχος είναι ο νευροδιαβιβαστής ενός νευρώνα, δεν μπορεί να χρησιμοποιηθεί το `nt_type` των εξερχόμενων ακμών του ως feature. Τα εισερχόμενα (π.χ. «ποσοστό ανασταλτικών εισόδων») είναι εντάξει.
- Το `UNASGD` σημαίνει ότι η σύναψη δεν αντιστοιχίστηκε σε neuropil.

Τα neuropils (`_L`/`_R` = αριστερό/δεξί ημισφαίριο):
`AL, AME, AMMC, AOTU, ATL, AVLP, BU, CAN, CRE, EPA, FLA, GA, GOR, IB, ICL, IPS, LA, LAL, LH, LO, LOP, MB_CA, MB_ML, MB_PED, MB_VL, ME, PLP, PVLP, SCL, SIP, SLP, SMP, SPS, VES, WED` (με `_L`/`_R`), καθώς και οι κεντρικές `EB, FB, GNG, NO, OCG, PB, PRW, SAD, UNASGD`.
Οπτικός λοβός: `LA` (lamina), `ME` (medulla), `LO` (lobula), `LOP` (lobula plate), `AME`.
